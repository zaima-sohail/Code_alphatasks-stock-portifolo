# 📊 Stock Portfolio Tracker

A simple Python project to track stock portfolio performance using a CSV dataset.

## 🚀 Features

* Load data from CSV
* Calculate investment, current value, profit/loss
* Portfolio summary with return %

## 📁 Dataset Format

```csv
name,quantity,buy_price,current_price,sector
AAPL,10,150,180,Technology
TSLA,5,700,650,Automotive
```

## ⚙️ Setup

```bash
pip install pandas
```

## ▶️ Run

```bash
python tracker.py
```

## 📌 Output

* Total Investment
* Current Value
* Profit/Loss
* Return %
